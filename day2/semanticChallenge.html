HTML Noted

HTML (Hypertext Markup Language) is the standard markup language for documents designed to be displayed in a web browser. html can be assisted by technologies such as Cascading Style Sheets (CSS) and scripting languages such as JavaScript.

Git Noted

Git is a distributed version control system for tracking changes in source code during software development. git is designed for coordinating work among programmers, but it can be used to track changes in any set of files. Its goals include speed, data integrity, and support for distributed, non-linear workflows.
